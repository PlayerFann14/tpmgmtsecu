# LINDDUN — menaces pour la vie privée

Source : KU Leuven (~2010) ; « le STRIDE de la vie privée ». Cours E21 ch. 06/10.

## Les sept catégories
| Lettre | Menace | Définition |
|---|---|---|
| L | Linking · liaison | Relier plusieurs données ou actions à une même personne |
| I | Identifying · identification | Identifier une personne à partir de ses données |
| N | Non-repudiation | Ne plus pouvoir nier une action (mauvais pour la vie privée) |
| D | Detecting · détection | Déduire la présence ou l'activité d'une personne |
| D | Data disclosure · divulgation | Exposer des données personnelles |
| U | Unawareness · méconnaissance | La personne ne sait pas ou ne contrôle pas |
| N | Non-compliance · non-conformité | Ne pas respecter le RGPD ou les règles |

## Usage
- À utiliser quand le système traite des **données personnelles** (données de santé =
  catégorie particulière RGPD, art. 9).
- Conséquences typiques : fuite de données de santé, ré-identification, défaut de
  minimisation dans les journaux, absence de consentement/information.
